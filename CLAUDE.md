# Rules for this project

## Code
- Keep the code as simple and readable as possible: loops, dictionaries, basic pandas. Nothing advanced. I'm not a programmer, I studied economics.
- Comments: only a short title with # above each block. Never comments at the end of a line.
- No numbers in the code. The limits are in data/portfolio/rules.csv and the portfolio is in data/portfolio/products.csv.

## Git
- Always work on a branch and open a pull request. Never merge.
- Small commits with clear messages in English.

## Texts (README, IPS, notes)
- No dashes. Write directly, like a 22 year old would.
- Never put euro amounts or how much I invest each month in public files. Only percentages.

## Portfolio
- Portfolio changes only in January (IPS rule 10).
- Never change IPS.md unless I ask.

## Tests
- Always say whether the test used real prices or made-up ones.
